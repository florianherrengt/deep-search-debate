## Requirement

Critical UX requirement — every run needs a budget.

Before starting:

- Standard research
- Estimated: 250–450 credits
- Maximum: 500 credits

Internally:

1. Reserve the maximum.
2. Run the task.
3. Settle the actual amount.
4. Return unused credits.
5. Pause rather than exceed the limit.
6. Automatically restore credits when failure was caused by RethinkLoop.

## Why

Without a maximum budget, users will eventually receive an unexpectedly expensive run and stop trusting the system.
